# Leapmotor Malaysia Sales Advisor Portal

Upload all files in this folder to the root of your GitHub repository. Keep the assets folder intact.

To enable GitHub Pages: Settings → Pages → Deploy from a branch → select main and / (root) → Save.

The entry file is index.html. No installation or build command is required.

Quotation calculations run in the browser. Download PDF generates a one-page quotation with the selected car image. On supported phones, the WhatsApp button opens file sharing; on desktop it downloads the PDF for attachment.
